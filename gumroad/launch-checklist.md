# Launch Checklist -- iOS Claude Toolkit

---

## Pre-Launch (Do First)

- [ ] Create Gumroad account (or log into existing)
- [ ] Verify payout method is configured (Stripe or PayPal)
- [ ] Finalize product ZIP file (skills/, CLAUDE.md template, git hooks, guides)
- [ ] Test ZIP: download on a clean machine, follow quick-start guide, verify skills load

## Product Setup

- [ ] Upload product ZIP to Gumroad
- [ ] Set product name: "iOS Claude Toolkit"
- [ ] Set content type: Digital Product
- [ ] Set price: $29 (launch price)
- [ ] Enable "Pay what you want" with $29 minimum
- [ ] Create $99 team license variant (up to 10 developers)
- [ ] Write product description (paste from `product-listing.md`)
- [ ] Upload cover image (1280x720, clean design, "iOS Claude Toolkit" text, dark background)
- [ ] Upload preview images: skill directory structure screenshot, CLAUDE.md template excerpt
- [ ] Add tags: Claude Code, iOS, Swift, SwiftUI, Xcode, AI coding, developer tools, Claude AI
- [ ] Set URL slug: `ios-claude-toolkit`
- [ ] Enable refund policy (30-day, Gumroad default)

## Launch Distribution

- [ ] Write Twitter/X launch post (thread: what it is, why I built it, what's inside, link)
- [ ] Post to r/iOSProgramming (value-first: share 2-3 free tips from the workflow guide, mention toolkit)
- [ ] Post to r/ClaudeAI (focus on the skill authoring methodology and Claude Code workflow)
- [ ] Post to Indie Hackers (building-in-public angle: 75+ sessions, production app, first product)
- [ ] Add product link to GitHub profile README
- [ ] Add product link to Twitter/X bio
- [ ] Optional: Write a short blog post or dev.to article about building iOS apps with Claude Code

## Post-Launch (Week 1)

- [ ] Monitor Gumroad analytics daily (views, conversion rate, revenue)
- [ ] Respond to customer questions within 24 hours
- [ ] Track refund rate (target: under 5%)
- [ ] Collect early feedback (ask first 10 buyers what they'd improve)
- [ ] After 50 sales: raise price to $39
- [ ] Optional: Submit to claude.com/plugins directory (free listing, drives traffic)

## Post-Launch (Week 2-4)

- [ ] Publish testimonials on product page (with permission)
- [ ] Write a "lessons learned" follow-up post (drives secondary traffic)
- [ ] Evaluate whether team license is converting (if not, adjust pricing or positioning)
- [ ] Plan v1.1 update based on customer feedback
