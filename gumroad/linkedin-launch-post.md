## WHY EVERY LINE EXISTS — Psychology Breakdown

### HOOK (Lines 1-2, before the "see more" fold)

"Claude Code forgot my architecture rules for the 47th time."
- **60 characters** — fits within mobile fold (110-140 char limit)
- "47th time" uses **oddly specific number** psychology — specific numbers feel truthful, round numbers feel fabricated
- Names "Claude Code" — **audience filter** that stops the right eyeballs
- Opens a **frustration loop** (Zeigarnik effect) — reader needs to know what happened next

"So I stopped prompting and started engineering."
- **Status reframe** — "prompting" is what beginners do, "engineering" is what experts do
- Creates **curiosity gap** — engineering WHAT?
- Combined with line 1, total is ~108 chars — comfortably before mobile fold

### PROBLEM SECTION (4 arrows)

- **Pattern recognition**: Every iOS developer using AI tools has experienced ALL 4 of these
- Arrow format (→) forces **line-by-line scanning** — increases dwell time (the #1 algorithm signal)
- Each frustration is **concrete and specific**, not vague ("security violations" not "problems")
- 4 items is optimal — 3 feels thin, 5+ loses attention

### AGITATION LINE

"I was spending more time correcting the AI than writing code."
- **Loss aversion** (Kahneman): Losses feel 2x more painful than equivalent gains
- Frames the problem as **time theft** — the most scarce resource for developers
- **Identity threat**: "If this is me, I'm using the tool wrong" — creates cognitive dissonance that the solution resolves

### PIVOT

"The fix wasn't better prompts. It was permanent procedural memory."
- **Contrarian reframe**: Challenges the default assumption (better prompts = better results)
- "Permanent procedural memory" is a **novel concept** — new language creates intrigue
- Two short sentences create **momentum** — the reader is accelerating into the solution

### SOLUTION

- "No configuration. Drop into .claude/skills/ and they activate."
- **Friction removal**: The #1 objection to any tool is "how hard is setup?" — killed in 2 sentences
- Technical specificity (.claude/skills/) builds **credibility** with developer audience

### THREE EXAMPLES

- "Say X → Claude does Y" format shows the **transformation**, not the feature
- Each example is a **different concern**: workflow (commit), quality (review), security (scan)
- Concrete outputs ("severity report generated") make it **tangible** — not vaporware

### VALUE STACK (10 categories)

- **Dwell time maximizer**: Users who read a 10-item list spend 30-45+ seconds on this section alone
- Algorithm tracks dwell — this section alone can push the post above the 61-second threshold
- Arrow format maintains **visual consistency** with the problem section
- Each category name is **self-explanatory** — no jargon barrier
- "(OWASP + Trail of Bits)" and "(GitHub Actions + Fastlane)" add **authority signals** through name-dropping respected tools/frameworks

### CLOSING

"Every hour you spend re-teaching Claude your conventions is an hour you're not shipping."
- **Direct address** ("you") makes it personal
- **Loss aversion** again — reframes inaction as actively losing time
- "Shipping" is the **highest-status verb** in developer culture
- This line is designed to be the line people **screenshot and share**

### CTA

"Link in first comment."
- LinkedIn suppresses posts with external links in the body
- This 4-word CTA is the **industry standard** that LinkedIn's audience recognizes
- No "buy now" or "check it out" — **low pressure**, high trust
