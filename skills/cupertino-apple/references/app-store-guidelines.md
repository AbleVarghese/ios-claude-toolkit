# App Store Review Guidelines -- Compliance Reference

Detailed compliance mapping for each App Store Review Guidelines section relevant to iOS apps.

## 1. Safety (Guidelines 1.x)

| Rule | Requirement | Compliance Notes |
|------|-------------|------------------|
| 1.1 | Objectionable content | Ensure no objectionable UGC if applicable |
| 1.2 | User generated content | Implement moderation if UGC is present |
| 1.3 | Kids category | Mark if targeting children (COPPA) |
| 1.4 | Physical harm | N/A for most apps |
| 1.5 | Developer info | Contact info provided in App Store Connect |

## 2. Performance (Guidelines 2.x)

| Rule | Requirement | Compliance Notes |
|------|-------------|------------------|
| 2.1 | App completeness | Fully functional, no placeholder content |
| 2.3 | Accurate metadata | Screenshots and description match functionality |
| 2.4 | Hardware compatibility | Universal iOS support for declared targets |
| 2.5 | Software requirements | Use latest stable APIs |

## 3. Business (Guidelines 3.x)

| Rule | Requirement | Compliance Notes |
|------|-------------|------------------|
| 3.1.1 | In-app purchase | Subscriptions via StoreKit where required |
| 3.1.5(a) | Person-to-person payments | Allowed for money transfer apps |
| 3.2.1 | Acceptable business | Verify business model compliance |

## 4. Design (Guidelines 4.x)

| Rule | Requirement | Compliance Notes |
|------|-------------|------------------|
| 4.0 | HIG compliance | Native SwiftUI/UIKit patterns |
| 4.2 | Minimum functionality | Full feature set, not a thin wrapper |
| 4.4 | Extensions | Comply if using app extensions |

## 5. Legal (Guidelines 5.x)

| Rule | Requirement | Compliance Notes |
|------|-------------|------------------|
| 5.1 | Privacy | Privacy policy URL, ATT if tracking |
| 5.1.1 | Data collection | Privacy labels accurate and complete |
| 5.1.2 | Data use | All data use disclosed in privacy policy |
| 5.2 | Intellectual property | All content original or licensed |
| 5.3 | Gaming/gambling | N/A unless applicable |
